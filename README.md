# Flood Object Detection YOLO11

Aplikasi web Flask untuk deteksi kendaraan pada kondisi banjir menggunakan YOLO11.

## Menyiapkan environment

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Di Windows, aktifkan virtual environment dengan `.venv\Scripts\activate`.

## Menjalankan aplikasi

```bash
python app.py
```

Kerangka proyek ini belum berisi implementasi fitur aplikasi.
